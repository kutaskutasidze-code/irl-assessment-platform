# IRL Assessment Platform

![Deployment Status](https://img.shields.io/badge/deployment-vercel-black?logo=vercel)
![Status](https://img.shields.io/badge/status-production-success)

**Innovation Readiness Level Assessment Platform for Startups**

Complete production-ready system with authentication, assessments, and action plans.

## 🚀 Live Demo

**Frontend:** https://kutaskutasidze-code.github.io/irl-assessment-platform/
**Backend API:** Deployed on Vercel (configured)

## ✨ Features

### For Startups
- 📊 Comprehensive IRL assessment (20 industry categories)
- 🎯 5-dimension scoring (Business, Technology, Customer, Operations, Financial)
- 📈 Enhanced results visualization with dimension breakdown
- 🏆 Achievement certificates (downloadable)
- 📱 Progress tracking across devices

### For Organizations
- 👥 Manage multiple startups
- 📋 Create and track action plans
- 📊 Portfolio analytics dashboard
- 🔍 Detailed assessment insights

### For Admins
- 🔐 Full platform management
- 📊 Platform-wide statistics
- 👤 User management

## 🛠️ Technology Stack

**Frontend:**
- HTML5, CSS3, JavaScript (ES6+)
- Chart.js for visualizations
- Responsive design

**Backend:**
- Node.js + Express
- PostgreSQL database
- JWT authentication
- RESTful API

**Deployment:**
- Frontend: GitHub Pages
- Backend: Vercel (Serverless)
- Database: Vercel Postgres

## 📦 Quick Start

### Frontend Development
```bash
# Clone repository
git clone https://github.com/kutaskutasidze-code/irl-assessment-platform.git
cd irl-assessment-platform

# Open in browser
open index.html
```

### Backend Development
```bash
# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Edit .env with your database credentials

# Start server
npm start
```

## 🚢 Deployment

### Vercel (Recommended)
1. Connect GitHub repository to Vercel
2. Add Vercel Postgres database
3. Set environment variables
4. Push to main branch → Auto-deploy!

See [VERCEL_DEPLOYMENT.md](VERCEL_DEPLOYMENT.md) for detailed instructions.
